Claude Code가 일하는 순서

말만 하는 게 아니라 끝까지 해

부탁 하나를 받으면 Claude는 스스로 살펴보고, 계획하고, 만들고, 확인해. 확인하다 문제가 보이면 다시 고치고.

👀 살펴보기→📝 계획→✏️ 만들기→🔍 확인↺ 다시

이렇게 여러 단계를 스스로 이어 가는 AI를 에이전트(agent)라고 불러. 채팅 Claude가 “한 번 묻고 한 번 답하기”라면, 에이전트는 “맡기면 끝까지 해 오기”야.

    Claude Code를 만나는 곳

    문은 여러 개, 안에 있는 Claude는 하나

    🌐

    웹

    claude.ai/code

    설치 없이 브라우저에서. 내 컴퓨터가 아니라 GitHub 저장소를 연결해서 인터넷 너머 컴퓨터에서 일해.

    ⭐ 우리가 들어갈 문🖥️

    데스크톱 앱

    Claude 앱 → Code 탭

    내 컴퓨터 폴더에서 일해. 허락은 버튼으로, 바뀐 내용은 눈으로 보면서. 처음 시작하기 딱 좋아.

    ⌨️

    터미널

    까만 화면에 claude

    개발자들이 많이 쓰는 문. 버튼 대신 글자로 주고받아. 다음 장에서 살짝 구경해 보자.

    문만 다르고, 일하는 방식은 똑같아. 폴더를 열어 주고 → 부탁하고 → 허락하고 → 확인하기. 데스크톱 앱에서 익힌 이 흐름은 나중에 어느 문으로 들어가도 그대로 통해. (코드 편집기 VS Code 안에서 여는 문도 있어.)
    한 번쯤 궁금했던 그것

    까만 화면은 글로 말 거는 창이야

    평소엔 마우스로 폴더를 열고 파일을 더블클릭하지? 터미널에서는 같은 일을 글자 한 줄로 시켜. 그 한 줄을 명령어라고 해.

    📂 폴더 더블클릭해서 들어가기=cd 폴더이름
    👀 폴더 안 파일 보기=dir
    🌐 파일 더블클릭해서 열기=start 파일이름

    사실 Claude Code도 뒤에서 이런 명령을 써. Claude가 “이 명령 실행해도 돼?”라고 물을 때 보이는 게 바로 이런 한 줄이야. 모르는 명령이면 “이게 뭐 하는 거야?”라고 되물으면 돼.

    Windows PowerShell
    
      
    
      
    데스크톱 앱 안에도 터미널 창이 숨어 있어. Ctrl + `(숫자 1 왼쪽 키)로 열어 봐. 구경만 해도 돼.

      이상해. 고쳐.
      사진이 너무 커서 화면을 꽉 채워. 화면 너비의 절반쯤으로 줄여 줘.
      
      
      블로그에 로그인에 댓글까지 한 번에 다 만들어 줘
      먼저 글 목록 페이지만 만들자. 그게 되면 다음 걸 하자.
      
    
      
    
      
      
      🎯
      구체적으로
      무엇을, 어디에, 어떤 느낌으로. 머릿속 그림을 말로 꺼내 줘.
      
      
      🧩
      작게 나눠서
      한 번에 하나씩. 되는 걸 확인하고 다음으로 가면 덜 꼬여.
      
      
      🤔
      “헷갈리면 먼저 물어봐”
      이 한마디를 붙이면 Claude가 짐작으로 밀어붙이지 않고 되물어 줘.
      
      
      🧑‍🏫
      “왜 이렇게 했어?”
      만든 걸 설명해 달라고 해 봐. 이게 바로 공부야. 모르는 줄은 “이 줄 무슨 뜻이야?”
      
    
      
  
      
  
      큰일을 맡길 땐 Plan 모드로 “먼저 계획만 보여 줘”부터. 계획이 마음에 들면 그때 만들라고 하면 돼.
      

      



      
  
      
    
      
      Claude에게 남기는 쪽지
      
      CLAUDE.md에 적어 두면 매번 말 안 해도 돼
      
      
      새 대화를 시작하면 Claude는 앞 대화를 다 기억하지 못한 채 시작해. 그래서 폴더에 CLAUDE.md라는 쪽지를 두면, 대화를 시작할 때마다 그걸 먼저 읽어.
      
      
      Git 안내서의 README가 사람을 위한 표지라면, CLAUDE.md는 Claude를 위한 쪽지야. 직접 쓰기 어려우면 “나에 대해 알려 줄 테니 CLAUDE.md 만들어 줘”라고 부탁해.

      🤖Agent
      에이전트
      맡기면 여러 단계를 스스로 이어서 해 오는 AI. Claude Code가 바로 이것.
      
    
      💬Prompt
      부탁 · 프롬프트
      Claude에게 보내는 말. 구체적일수록 결과가 좋아.
      
    
      🗂️Session
      대화 한 판
      시작부터 끝까지의 대화 하나. 사이드바에 남아서 나중에 다시 열 수 있어.
      
    
      📂Folder · Project
      작업 폴더
      Claude가 일하는 공간. 시작할 때 네가 골라 줘.
      
    
      🔐Permission
      허락
      파일을 고치거나 명령을 실행하기 전에 Claude가 묻는 것.
      
    
      🧭Mode
      얼마나 물어볼지
      Manual · Accept edits · Plan. 입력창 아래에서 바꿔.
      
    
      🟩Changes · Diff
      바뀐 부분
      초록은 더한 줄, 빨강은 뺀 줄. +12 −1처럼 숫자로도 보여.
      
    
      ⌨️Terminal
      까만 화면
      글자로 컴퓨터에 명령하는 창.
      
    
      ▶️Command
      명령어
      터미널에 치는 한 줄. cd, dir 같은 것.
      
    
      📝CLAUDE.md
      Claude용 쪽지
      대화를 시작할 때마다 Claude가 먼저 읽는 안내문.
      
    
      🧠Model
      두뇌 종류
      Claude에도 여러 버전이 있어. 입력창 아래에서 고를 수 있어.
      
    
      📏Context
      지금 기억하는 범위
      Claude가 한꺼번에 보고 있는 대화·파일의 양. 너무 길어지면 새 대화로.
